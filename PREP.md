# Get ready for the Gameshow

About 30–45 minutes. Do it before the day: venue wifi is not the place to download things.

**Can't get it all working? Come anyway.** You can vote on your phone and follow on the big screen, and take this repo home.

## What to bring

- A charged laptop (Mac or Windows) and its charger
- Your phone (for voting)

## 1. Install the Claude desktop app

Download it from [claude.ai/download](https://claude.ai/download), sign in, and find the **Code** tab. That's Claude Code with a friendly window, and the easiest way in.

(Already use a terminal or Cursor? Claude Code works there too.)

## 2. Get Claude Pro

Claude Code needs a paid Claude plan. Sign up at [claude.ai](https://claude.ai) and choose **Pro**.

Already paying for another AI coding tool, like Cursor or Copilot? Use that instead: this repo is just files, so any of them will work.

## 3. Get this repo onto your laptop

In the Claude desktop app's Code tab, start a new session and ask:

> Clone https://github.com/creativefreya/techella-unlikely-gameshow into my Documents folder and open it

No Git yet? Claude will notice and offer to install it. On a Mac, a pop-up appears: click **Install**.

Or in a terminal:

```bash
git clone https://github.com/creativefreya/techella-unlikely-gameshow.git
```

## 4. Run the check

With the repo open in Claude Code, type:

```
/preflight
```

Claude checks your laptop (Git, Node.js, the repo) and tells you in plain English what, if anything, needs fixing. Then it asks whether you want it to fix everything for you, or give you one command at a time to run yourself. All green = you're ready.

## On the day

Open the repo in Claude Code and type `git pull` (or ask Claude to "pull the latest"). That gets the round skills.

Step-by-step page with copy buttons: [augmenteddesigner.com/resources/techella-gameshow](https://augmenteddesigner.com/resources/techella-gameshow/)
